
# AI Development Work Log

## Project

**Student Task Planner**

## Purpose

A standalone React application that helps students organize tasks, track completion, set priorities, and manage deadlines.

## AI Assistance

AI assistance was used throughout development to help implement React functionality, improve the user interface, troubleshoot styling issues, and prepare project documentation.

### Features Developed with AI Assistance

- Create tasks with a task title.
- Mark tasks as completed or pending.
- Delete individual tasks.
- Filter tasks by All, Pending, and Completed.
- Display total, pending, and completed task counts.
- Save and restore tasks using browser localStorage.
- Assign Low, Medium, or High priority to tasks.
- Set optional due dates.
- Display due dates and overdue indicators.
- Clear completed tasks.
- Style the interface with CSS and responsive layout rules.

## Limitations

- Tasks are stored in the current browser's localStorage.
- Tasks are not synchronized between different browsers or devices.
- The application does not currently use a backend or online database.
